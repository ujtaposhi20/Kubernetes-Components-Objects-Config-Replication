# Overview

This is the replication package containing the 'Survey and Interview Data', 'Source Codes', 'CSV Files Generated by Code' and 'patterns_searched_by_the_scanner.csv' used for the paper. 

## Contents 

The contents of the package are: 

### Survey and Interview Data

- 'InterviewGuide' - contains semi-structured interview questionnaire that we use for RQ1 
- 'raw-transcript': contains all the interview transcripts for this study that we use for RQ1 
- 'CodeBook' - The thematic analysis information that we use for RQ1
- 'OnlineSurveyQuestions' - contains the questions designed for the survey that we use for RQ1
- 'OnlineSurveyData'-contains the dataset that we gathered from the survey that we use for RQ1

### Source Codes 

- 'repo_filtering.py', contains the code for filtering a large pool of repositories using criterion 1 to criterion 4 for RQ1.

- 'bulk_clone_full.py' contains code for cloning 1429 filtered repos (filtered by applying criterion 1 to criterion 4) on the local device.

- 'k8s_focused scanner.py', contains code to scan 1429 repos following the patterns of "patterns_searched_by_the_scanner.csv" file in in the first place and build important files like repo_summary.csv with repository names, object_counts etc. This helps us to identify which Persisten Entities (PEs), Configuration management is present in which repo for RQ1.

- 'release_k8s_info.py', contains code to identify REPO, RELEASEINDEX, RELEASEDATE, K8SFIRSTCOMMITDATE from the cloned repos to support RQ1.

- 'compute_cadence.py' contains code to find REPO, OVERALLRELEASECADENCE, POSTK8SRELEASECADENCE, PREK8SRELEASECADENCE from the output that we get from 'release_k8s_info.py' for RQ2.

- 'categorize_cadence.py', contains code to apply criterion 5 to filter the final repos (565 repos),  identifying POSTK8SRELEASECADENCE and their respective CADENCEGROUP (Rapid+, Rapid, Modern, Slow) for RQ2.

- 'repo_attributes.py'is used the analyze the repository attributes (final 565 repos' attributes) like commits, contributors, stars, config_scripts count etc.

- 'obj_in_repo_percent.py' builds the Repo% column of Table V: it filters repo_summary.csv down to the 565-repo cadence cohort, then for each of the 19 PEs counts how many cohort repos have it present for RQ1.

- 'config_mangement_percent.py' builds Table VII for the 565-repos for each config-management tool (Flux, ArgoCD, Ansible, Terraform, Helm) it auto-detects the matching repo_summary.csv column by keyword, counts how many cohort repos use it and the percentage, then computes Cohen's h between that repo adoption rate and the tool's survey "Yes" rate and labels it Alignment / Partial Alignment / Divergence, writing config_method_percent.csv for RQ2.

-'obj_per_category_for_heatmap.py', contains code for showing PE proportion using equation 1 of the paper, and is used for RQ1.

- 'monthly_object_release.py' contains code for scanning each post-K8S cadence repo, walks git history for newly-added YAML files (--diff-filter=A), parses their kind: fields, counts the 17 object types per month, sums across repos, joins monthly release counts, and writes monthly_object_release_cadence.csv for RQ2.

- 'monthly_scheduling_release_v2.py' contains codes for scanning each post-K8S cadence repos, structurally counts the 3 scheduling features (Node Affinity & Pod Anti-Affinity under an affinity: block, list-valued taints), and writes per-month occurrence counts with release counts to monthly_scheduling_release_cadence.csv for RQ2.

- 'compute_pe_per_month.py' reads the monthly object and scheduling count CSVs and computes Formula (2) PE-per-month percentages into pe_per_month.csv and pe_per_month_wide.csv for RQ2.

- 'plot_figure2.py' is used to build Figure 2 of the paper to support the answer to RQ2 from pe_per_month.csv file for RQ 2.

- 'config_cadence.py' — Joins the 565-repo cohort with repo_summary.csv to build the long-format config-management vs. cadence-group contingency file (with manual IAC reclassification for manusa/yakc and manusa/yakd) for RQ2.

- 'avg_median_for_configTable.py' builds Table IX: it scans 565 repos' cloned files to detect five config tools (Helm via Chart.yaml, Terraform via .tf, Ansible via a roles/ dir / ansible.cfg / playbooks, ArgoCD via argoproj.io and Flux via fluxcd.io inside YAML), sets per-repo 0/1 flags, rolls them into three methods (GitOps, IaC, PackageManager), then reports the mean and median of each method per cadence group, writing table_ix_config_method.csv for RQ2.

- 'chisquare.py' Performs a Chi-Square test of independence between two categorical columns of a CSV.

-'time-plot.py' plots time-series line charts (optionally grouped and smoothed with a rolling mean) of object/release counts over months for RQ2.

- 'wavelet.py' Computes wavelet coherence between two monthly time series (e.g., object count vs. release count) and generates scale-averaged line and/or time-frequency contour plots for RQ2.

### patterns_searched_by_the_scanner.csv - Contains all the pattens to scan the PEs, workloads, configuration managements from the repositories.

### CSV Files Generated by Code - This folder contains all the .csv files generated from the source codes.
